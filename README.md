# 일비서

헤드헌팅 업무용 **할 일·일정 개인 비서**.  
아버지 엑셀 「할 일 계획 및 정리 방법」 규칙을 웹으로 옮긴 첫 슬라이스입니다.

## 기능

- 엑셀형 TO DO 그리드 (직접 추가·수정·삭제·완료)
- 정렬: **스팟(당일)** → **지속(~목표일)** → **언젠가(시급·중요)**, 유사 할일 묶음
- 완료 건은 **완료 기록**으로 이동
- 입력: 직접 기입 / 휴대폰 메모 붙여넣기 / 사진 OCR(목) / 캘린더 mock·ICS·JSON
- `localStorage`에 저장 — 새로고침 후에도 유지

## 실행

```bash
npm install
npm run dev -- -p 4317
```

브라우저: [http://127.0.0.1:4317](http://127.0.0.1:4317)

## 스택

Next.js · TypeScript · Tailwind CSS · shadcn/ui
